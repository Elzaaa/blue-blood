# Blue Blood

Игра на двоих за одной клавиатурой. Python + pygame.

## Управление
| | бегать | действие | перк |
|---|---|---|---|
| Игрок 1 | WASD | E (или Пробел) | Q |
| Игрок 2 | стрелки | `.` (или Enter) | `/` (или Правый Shift) |

Роли меняются каждый раунд. Матч — до 3 побед. `P`/`Esc` — пауза.

## Кот убегает
- Побеждает, если **продержится 1:30** или **соберёт 5 рыбок**.
- **Действие** — то, что ближе: открыть/закрыть **дверь**, разбить **вазу**, залезть в **шкаф**.
- **Ваза** → на полу осколки (15 сек). Лис по ним бежит вдвое медленнее.
- **Шкаф**: кот исчезает, все шкафы шуршат. Внутри стрелками/WASD перебирается в соседний шкаф.
  Сидеть максимум 6 сек, затем шкаф 6 сек недоступен.
- **Перк — чёрная кошка**: 8 сек гоняется за лисом. Поймает — у лиса минус сердечко.
  У лиса 3 сердечка; кончились — кот победил.

## Лис догоняет
- Побеждает, если **поймает кота**.
- **Действие** — рывок.
- Постоять 0.7 сек у дверцы шкафа — **вынюхать** кота. Угадал — победа, нет — «пусто!».
- **Курица** на кухне: 1.2 сек ест (стоит на месте), потом 6 сек бегает быстрее.
- Упёрся в закрытую дверь — процарапывает её.
- **Перк — бабушка**: появляется недалеко от кота, ловит его и держит 2.5 сек.

## Сюрприз
Один раз за раунд **гаснет свет** на 12 сек — видно только вокруг персонажей.

Все числа баланса — в начале `logic.py`.

## Запуск на компьютере
```
pip install pygame
python main.py
```

## В браузере
```
pip install pygbag
pygbag blueblood        # из папки, где лежит папка blueblood
```
Открой http://localhost:8000. Папку `blueblood/build/web` можно залить на itch.io или GitHub Pages.

## Файлы
- `logic.py` — правила (без pygame, пригодится для онлайна)
- `sprites.py` — пиксель-арт в коде; свои PNG клади в `assets/`
- `main.py` — отрисовка, управление, меню, матч
